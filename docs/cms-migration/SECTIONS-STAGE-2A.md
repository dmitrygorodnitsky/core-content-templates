# Этап 2A перенесён на prod

17 ноября 2026 года перенесены:

- [Field Service](https://prod.servicewand.com/industries/field-service)
- [Snow Removal](https://prod.servicewand.com/industries/field-service/snow-removal-software)
- [Страница-переадресация](https://prod.servicewand.com/industries/field-service/snow-removal-software-new)

**Цены и домен не изменялись. Блокеров этой очереди нет.**

## Что загрузили

Три страницы, 20 блоков и три медиабиблиотеки. Из 46 зависимостей медиа (5 269 087 байт) 42 файла загружены, четыре переиспользованы из первого этапа после сверки хешей. Общая библиотека первого этапа также переиспользована. Всего 93 операции: 88 записей с проверкой результата и пять переиспользований.

Блоки сохранили владельца SYSTEM, страницы — SERVICEWAND и исходные пустые permissions. Целевые связи разрешены по кодам, полному пути дерева, организации и имени/хешу медиа. Source ID не использованы как destination ID.

## Проверки

- 27 итоговых определений конфигурации совпали с пакетом по переносимым полям.
- Три CMS preview и три публичных адреса вернули HTML с HTTP 200.
- Все 46 медиа доступны без авторизации и совпадают с источником по SHA-256, включая видео через stream-маршрут.
- Метаданные и optimistic-версии 51 ранее существовавшей страницы/блока не изменились.
- Ответ публичного каталога Snow Removal до и после загрузки совпал целиком: 18 ценовых строк. Записей в продукты или цены не было.
- Скрипт переадресации проверен с обычным, английским и французским путём: язык, query string и hash сохраняются.
- Проверки порядка зависимостей, разрешения media-параметров, допустимых маршрутов записи, четыре теста runtime и целостность ZIP прошли.

Переадресация сохранена как в источнике: HTTP 200 с JavaScript/meta-refresh, а не HTTP 301. JavaScript использует относительный адрес. Canonical и резервный meta-refresh остаются на servicewand.com; до переключения домена этот резервный путь ведёт на старый сервер.

Проверки охватывают серверный рендеринг, публичные HTTP-ответы, данные и изолированное выполнение скрипта перехода. Визуальный браузерный аудит и отправка заявок не выполнялись. Оплата и расписания не включались.

## Что осталось

В основном плане второго этапа остаются **пять страниц и 90 блоков**: блог, Use Cases, старая документация и Landscaping. Их проблемы не изменились: повреждённые изображения, шесть отсутствующих CSS/JS, сопоставление авторов блога и анонимный доступ к тарифам Landscaping. [Актуальный план](REMAINING-STAGE-2.md).
