# Первый этап CMS: перенесён на prod

17 ноября 2026 года корневой сайт и его формы перенесены с servicewand.com на **prod.servicewand.com**. Публичный домен не переключали.

## Что перенесли

| Состав | Количество |
|---|---:|
| Блоки дерева CORPORATE_LANDING_JTE | 35 |
| Страницы | 10 |
| Типы форм, включая родителей | 10 |
| Workflow FORM | 1: 3 состояния, 2 перехода |
| Медиабиблиотека | 1 |
| Медиафайлы | 53; 8 609 583 байта |

Страницы: `/index.html`, `/request-demo.html`, `/partner.html`, `/privacy-policy.html`, `/terms-and-conditions.html`, `/success.html`, `/error.html`, `/documentation/introduction.html`, `/snow-removal-request-demo.html`, `/field-service-early-access.html`.

Всего выполнены 146 операций загрузки: создание записей и отдельное связывание содержимого блоков и переходов workflow. Идентификаторы назначения получены по кодам, пути дерева и результатам чтения с prod. ID исходного сервера не использованы как целевые.

## Что проверили

- Итоговые 57 определений конфигурации совпадают с пакетом по переносимым полям, включая права, значения страниц, наследование форм и переходы workflow.
- Все 10 страниц собираются CMS с HTTP 200 и открываются на публичных адресах prod.
- Все 10 схем форм доступны без авторизации. Параметр `locale=en` вызывает штатный редирект на адрес без параметра, как на источнике; конечные адреса возвращают JSON с HTTP 200.
- Все 53 файла доступны без авторизации и совпадают с исходниками по SHA-256.
- Шесть существовавших до переноса записей AUTH/SAS сохранили прежние метаданные и версии; операций записи в них не было.
- Семь проверок пакета и четыре проверки исполнительного инструмента прошли.

Это проверка сохранения, серверного HTML и HTTP-доступности. Отправку реальных заявок, интерактивный браузерный сценарий и визуальное сравнение не выполняли.

## Поведение сохранено

| Формы страницы | Организация получателя |
|---|---|
| Request Demo / Snow Demo | SERVICEWAND |
| Главная / Partner / Field Service Early Access | PNI |

Request Demo по-прежнему использует GENERAL_PARTNERS_FORM. Данные существующих заявок не переносили. Права, оплата и расписания не изменялись.

Три устаревшие группы значений страниц сохранены в архиве, но не назначены другим блокам: TABLE_COL_CRM, DOCUMENT_CODE и FEAT_CARD_3_TITLE. Последняя относится к другому дереву шаблонов.

При загрузке обработаны два технических отличия: разные файлы могут иметь одинаковые имена (идентичность проверяется также по хешу); Core меняет порядок enabledTemplates (сравнивается набор, порядок атрибутов остаётся значимым). Неподтверждённые записи вслепую не повторялись.

## Что осталось

**Блокеров загрузки первого этапа нет.**

За пределами этапа остаются остальные деревья: Field Service, Snow Removal, Landscaping, Use Cases, блог, старая документация overview, PNI `/snow`, тестовые страницы. Главная содержит ссылки на эти разделы. Перед переключением всего servicewand.com нужно перенести или согласовать оставшиеся разделы и проверить навигацию, языки и отправку форм.

Абсолютные ссылки на servicewand.com сохранены под будущий домен; до переключения они ведут на исходный сервер. Переключение домена выполняет backend.
