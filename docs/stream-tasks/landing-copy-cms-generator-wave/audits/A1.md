## Residuals

- Generated root HTML still uses the root child-slot marker; the future uploader/render adapter must translate markers into the exact CMS/JTE child rendering directive if the live CMS requires a different include syntax.
- Generated template identifiers are stable codes, not persisted CMS UUIDs. The uploader layer must create/copy templates and map codes to live IDs.
- CSS collision candidates remain accepted at catalog level and should be addressed before multi-block CMS composition is used outside iframe isolation.
- The composer is deterministic for block selection specs and operator requests; real copy generation remains out of scope.
