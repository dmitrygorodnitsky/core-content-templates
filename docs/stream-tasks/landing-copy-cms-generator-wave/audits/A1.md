## Residuals

- Generated parent HTML uses named child-slot comments such as `<!-- cms-child-slot:FAQ_ITEMS -->`; the future uploader/render adapter must translate those markers into the exact CMS/JTE child render directive.
- Generated template identifiers are stable codes, not persisted CMS UUIDs. The uploader layer must create/copy templates and map codes to live IDs.
- CSS collision candidates remain accepted at catalog level and should be addressed before multi-block CMS composition is used outside iframe isolation.
- The generator is deterministic for normalized Markdown copy; freeform brief normalization remains a separate future layer.
