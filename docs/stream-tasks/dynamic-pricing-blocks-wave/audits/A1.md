## Implementation Summary
- Added one shared `window.LabPricing` runtime that builds the Core PIM request, caches by request signature, supports offline fixture URLs, normalizes Core PIM `prices` and `productTypes`, sorts by `SORT_ORDER_PRIORITY` with amount fallback, strips HTML tags from API text, detects custom pricing, and exposes normalized `plans` and `groups`.
- Wired `pricing.plans-flex` to opt-in dynamic rendering. Dynamic success fills existing card slots from normalized plans; disabled or failed dynamic loading keeps the static CMS-authored cards.
- Wired `pricing.matrix-collapsible` to opt-in dynamic rendering. Dynamic success rebuilds desktop rows and mobile accordion panels from normalized groups/rows; disabled or failed dynamic loading keeps the static matrix.
- Added compact SaaS, Sites, and Routes fixtures that preserve the raw Core PIM response shape needed for normalization without committing large API dumps.
- Added CMS parameters and editor notes for dynamic Core PIM configuration while preserving existing static fallback fields.
