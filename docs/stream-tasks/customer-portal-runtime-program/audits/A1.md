# A1 Audit — Customer Portal Runtime Program

Date: 2026-07-09
Status: passed with recorded residuals

## Result

The accepted Claude Design customer portal source was transferred into a
production runtime and packaged for CMS inspection. The runtime is native ES
modules, no React/bundler baseline, with route/config guards, fixture-first
module runtime, scoped commands, PIM live adapter support for pricing/products,
and generated CMS preview artifacts.

## What Landed

- `app-templates/customer-portal/runtime/**`
  - production transfer target from `design-inbox/`
  - dev toolbar and preview viewport contract removed
  - no old dev-only compatibility shims retained
- `runtime/src/config.js`, `runtime/src/router.js`
  - vertical profiles, root `data-portal-*` parsing, route registry, hash/history/memory mode, auth/unknown/disabled guards
- `runtime/src/portal-runtime.js`
  - fixture-first module loading, cache, normalized `state.moduleData`, async live path
- `runtime/src/modules/**`, `runtime/src/adapters/**`, `runtime/src/normalizers/**`
  - module descriptors, fixture adapter, Core PIM adapter, normalizers
- `app-templates/customer-portal/scripts/**`
  - route smoke, PIM adapter check, CMS export
- `app-templates/customer-portal/cms/**`
  - CMS metadata and root template
- `app-templates/customer-portal/dist/customer-portal-preview.html`
  - generated local CMS preview

## Residuals

- Live adapters for orders, proposals, services, checkout, calendar, activity,
  profile, and support are not opened because endpoint contracts are not present
  in the repo. Pricing/products have Core PIM adapter coverage.
- No repo-level production compile command was found; this template validates
  with syntax, JSON, adapter, export, and browser smoke checks.
- Playwright package is available from the bundled Codex runtime, but bundled
  Chromium is not installed in this environment. Browser smoke uses system
  Chrome via `PLAYWRIGHT_EXECUTABLE_PATH`.
- No CMS upload was performed.
