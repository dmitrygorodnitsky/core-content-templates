## Remediation Cycle 1

The audit findings were fixed as follows:

1. Health policy is now code-owned in `runtime/src/activation-policy.js`.
   `HEALTH_CONTROL_SET`, `HEALTH_SENSITIVE_IDS`, and
   `CARE_SURFACE_CLOSED_IDS` are literal frozen constants. Enforcement does not
   trust inventory-provided sensitivity or control-set declarations.
2. Negative mutation tests reject self-declassification, a modified top-level
   set, removed/relabelled required or missing controls, `opened_live`, and a
   locally opened sensitive surface.
3. Every Care `[data-action]` is inventoried and browser-clicked/traced. Exact
   DOM mutation tests reject a removed row/entity, relabelled action, or changed
   disposition.
4. Care controls that previously opened a drawer or failed only after effort
   are visibly unavailable at source: Care-surface `booking.open`,
   `order.reschedule`, `service.requestExtra`, Health `support.call`, and Health
   `order.open`.
5. Truthful cross-module fixture effects remain: Snow/Beauty `order.open`,
   Beauty `profile.managePlan`, and Beauty `cart.addItem`, each with exact route
   or entity readback. `openOrder` now rejects unknown fixture ids.
6. Care normalization strips `url`, `href`, `downloadUrl`, and `filename` from
   document metadata. `DocRow` ignores destination fields and always derives
   unavailable state from code policy. Raw and post-normalization malformed URL
   injections remain visibly unavailable, inert, and network-free.

The bundled/system runtime did not contain Ajv, `jsonschema`,
`check-jsonschema`, or another JSON Schema validator. The schema was still
strengthened to draft 2020-12 with strict object shapes, required fields,
`additionalProperties: false`, typed nested objects, and conditional
disposition/Health constraints. Code-owned validation and adversarial mutation
tests are mandatory regardless of validator availability.

git history. It was not rewritten as if the S5 truth-state divergence had
always existed.

change: pre-addendum smoke failed on `care-ready-hvac-1440` with 23,402 changed
implementation pixels against the persisted schema-v6 image. This was expected
and was not accepted as parity.

The harness contract was advanced to schema v7:

- exact unavailable inventory expanded from 56 to 97 rendered instances across
  the 31 affected matrix rows;
- raw reference/implementation images and metrics remain retained;
- changed components are accepted only when the complete component is contained
  in one exact control envelope and intersects that control's own border box;
- isolated patches or components extending beyond that envelope still fail;
- DOM metric differences are accepted only when the metric box matches an
  exact unavailable control border box;
- no broad mask, blanket padding, or reference mutation was added.
