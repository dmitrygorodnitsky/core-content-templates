# lab-ui compatibility facade

The executable landing-page catalog, compiler, content, and generated output
now live under [`app-templates/landing-page`](../../../app-templates/landing-page/README.md).

Legacy CLI paths under `scripts/` are thin forwarding wrappers. New code and
documentation must use the canonical `app-templates/landing-page/**` paths.
There are no compiler inputs or generated artifacts owned by this docs path.
